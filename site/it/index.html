Rispondere a domande e ripassare dopo qualche giorno funziona meglio che rileggere le slide (lo dice la ricerca). Le flashcard aiutano, ma scriverle richiede ore e da sole non spiegano niente. MDlearn ti dà entrambe le cose: appunti completi con gli esercizi dentro.

Come funziona

  1. Aggiungi i tuoi file

    PDF, slide, Word, appunti. O anche solo un argomento.

  2. L'AI scrive gli appunti

    Con esempi, formule ed esercizi. MDlearn controlla che ogni domanda abbia una risposta giusta.

  3. Ripassi 5-10 minuti al giorno

    L'app ti ripropone ogni concetto quando il ricordo inizia a svanire.

Basta ricopiare le slide a mano

Aggiungi tutto quello che hai, anche insieme: l'AI ne fa un corso diviso per argomenti.

Appunti da cui impari davvero

Formule spiegate termine per termine, grafici, diagrammi e animazioni, non elenchi puntati.

Basta risposte tirate a indovinare

Prima della risposta l'app ti chiede se eri sicuro. Se avevi tirato a indovinare, te la ripropone prima.

Fatichi a leggere? Cambia font.

Scegli un font più leggibile o quello per la dislessia, e la dimensione che vuoi. Poi evidenzia in sei colori e aggiungi le tue note.

I tuoi appunti sono tuoi

  • Nessun account

    Niente da registrare. Nemmeno questo sito ti traccia.

  • File normali

    Gli appunti sono file di testo sul tuo computer. Si aprono anche senza MDlearn.

  • L'AI la scegli tu

    Un'AI online vede i file che le dai. Per tenere tutto offline usa un'AI locale con Ollama.

Download

L'app è nuova e non ha ancora la firma digitale a pagamento, quindi la prima volta Windows o macOS potrebbero avvisarti. È normale, e il codice è pubblico su GitHub.

Windows

Installer (.exe)

"Windows ha protetto il PC" → Ulteriori informazioni → Esegui comunque.

macOS

Chip Apple (.dmg)Intel (.dmg)

Trascinala in Applicazioni, aprila una volta, poi Impostazioni di Sistema → Privacy e sicurezza → Apri comunque.

Linux

.AppImage.deb

Rendi eseguibile l'AppImage, poi aprila.

Comandi

chmod +x MDlearn-*.AppImage (serve libfuse2), oppure installa il .deb: sudo apt install ./MDlearn-*.deb

Terminale

npx mdlearn studio

Apre MDlearn nel browser. Serve Node.js 22.15 o più recente.

Verifica (facoltativo)

SHA256SUMS.txt

Controlla che il file corrisponda all'elenco.

Come

Windows: certutil -hashfile FILE SHA256
macOS e Linux: shasum -a 256 FILE

Domande

È gratis?

Sì. È open source, con licenza MIT.

Windows dice che l'app non è riconosciuta: è sicura?

L'app non è ancora firmata, quindi Windows non la conosce. Clicca Ulteriori informazioni → Esegui comunque. Il codice è pubblico su GitHub e puoi controllare il file scaricato con SHA256SUMS.txt.

Se è attivo Smart App Control, Windows 11 blocca le app non firmate senza il pulsante "Esegui comunque". La firma dell'app è nella roadmap.

Serve saper programmare?

No. Basta l'app desktop: niente terminale, niente Node.js.

Quale AI mi serve?

Una che usi già: Claude, ChatGPT, Gemini… Va bene anche la versione chat.

In che lingue c'è?

L'app è in italiano, inglese, spagnolo, francese e catalano. I corsi possono essere in qualsiasi lingua.

Funziona sul telefono?

Puoi studiare dal telefono sulla rete di casa, ma l'app gira sul computer. Apri questa pagina dal PC per scaricarla.

Dove finiscono i miei dati?

Restano sul tuo disco. Vedi la sezione privacy.
